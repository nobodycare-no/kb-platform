## 3. RAGAS 迭代评估闭环（核心章节）

黄金集：`deploy/ragas/golden.jsonl`（12 条：IT/HR/财务各含事实题 + 2 条拒答预期）
运行器：`deploy/ragas/run_eval.py`（走真实 /api/ai/chat/stream 全链路）
报告 CSV：`deploy/ragas/ragas_report_*.csv`

### 迭代过程（RAGAS → 发现 → 针对性调整）

| 轮次 | 命中 | 发现的问题 | 调整措施 |
|------|------|-----------|---------|
| 1 | 9/12 | 评估口径错误：HR/财务行标记"应拒答"，但评估者超管可见全部；另发现 runner 双重 Bearer 导致全 401 | 校准 golden 口径（权限拒绝行为改由冒烟场景②覆盖）；修复 token 传参 + 增加 HTTP 状态断言 |
| 2 | 10/12 | 「年假有几天？」模型编造了带 [1][2][3] 假引用的年假天数（忠实性失败——语料仅有请假流程） | 尝试重排分绝对阈值 0.30 门控 |
| 3 | 10/12 | 分数分布探测显示绝对阈值不可靠：合法的「迟到」题仅 0.083，而弱相关的「年假」有 0.158 | 阈值降至 0.05 仅拦截完全无关（股票=0.0 ✓被拦）；同时强化 Prompt 拒答规则 |
| 4 | 11/12 | 年假题仍编造具体天数——片段外数值混入 | Prompt 新增规则 2：「片段中未出现的具体数值（天数/金额/比例/期限）一律视为未知」 |
| **5** | **12/12** | — | **收敛 ✅** |

### 行为指标汇总（最终轮）

| 指标 | 数值 |
|------|------|
| 黄金集命中率 | **12/12 = 100%** |
| 平均端到端延迟 | ≈ 6.0s（其中 Qwen3-8B 流式生成占主导） |
| 拒答准确率 | 2/2（未覆盖问题均正确拒答且不编造数值） |
| 权限缺失提示准确率 | 100%（冒烟场景②：3 个缺失单元逐一列出） |

### 四指标说明

faithfulness / answer_relevancy / context_precision / context_recall 的完整计算需以
GPU 端 Qwen3-8B 作为评测 judge（ragas 库 + langchain-openai 包装），命令已固化在
`deploy/ragas/run_eval.py` 文档字符串中。本轮已产出行为层 CSV 与调优记录；
四指标数值将在 GPU 稳定供给时段补跑并归档至本目录。
