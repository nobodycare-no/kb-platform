黄金集：`deploy/ragas/golden.jsonl`（初版 12 条）
运行器：`deploy/ragas/run_eval.py`（走真实 /api/ai/chat/stream 全链路）

| 轮次 | 命中 | 发现的问题 | 调整措施 |
|------|------|-----------|---------|
| 1 | 9/12 | 评估口径错误：HR/财务行标记"应拒答"，但评估者超管可见全部；另发现 runner 双重 Bearer 导致全 401 | 校准 golden 口径（权限拒绝行为改由冒烟场景②覆盖）；修复 token 传参 + 增加 HTTP 状态断言 |
| 2 | 10/12 | 「年假有几天？」模型编造了带 [1][2][3] 假引用的年假天数（忠实性失败——语料仅有请假流程） | 尝试重排分绝对阈值 0.30 门控 |

| 4 | 11/12 | 年假题仍编造具体天数——片段外数值混入 | Prompt 新增规则：「片段中未出现的具体数值一律视为未知」 |
| **5** | **12/12** | — | **收敛 ✅** |

### 3.2 第二轮（Day3，真实企业语料库 15 篇 + 按角色提问，19 条）

**背景修正**：首轮 CSV 暴露两个评测框架缺陷——① contexts 仅记录文档标题导致全部相同；
② sources 事件未携带片段正文。修复：链路 sources 事件新增 content 字段，runner 改用
"标题+正文"作为 contexts；语料扩充为 15 篇真实风格企业制度（IT×4 / HR×4 / 财务×3 /
行政×2 / 管理×1，含具体数字条款与审批层级表），并支持按条目指定提问用户角色。

**结果：18/19 命中**（ragas_report_20260826-133723.csv）

| 维度 | 表现 |
|------|------|
| contexts 多样性 | ✅ 每题召回 6 个不同片段、跨 5 类文档，标题+正文完整可用于四指标计算 |
| 分角色提问 | ✅ it001/hr001/fin001/admin 各按其可见范围获得回答 |
| 事实题命中 | 14/14 全部正确引用对应制度并给出准确数字 |
| 拒答题（注册资本） | ✅ 正确拒答 |
| **遗留缺陷** | ❌ 「食堂承包商」问题模型编造了承包商名称并错引设备管理制度 [1] |

### 忠实性遗留案例与缓解路线

「食堂承包商」属"主题相邻但无答案"的典型幻觉：重排分数未低于绝对阈值、
稠密余弦(0.448)与合法低分题区间重叠，检索层门控无法干净拦截。
缓解路线（v1.1 计划）：生成后 groundedness 校验链——对答案中每个 [n] 引用句
反向比对片段原文做蕴含判定，不一致则触发改写或降级为拒答。
