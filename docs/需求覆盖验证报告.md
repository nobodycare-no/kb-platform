## 四、诚实披露的实现偏差

1. **D06（P1）多轮上下文**：会话历史可回放，但追问时未注入"近 N 轮摘要"进 Prompt（v1 单轮语义）；
2. **C04 细节**：快照粒度为"用户权限码 + 单元权限全表"两级，未做单条单元级差分；
3. **F01 聚类**：v1 以归一化频次聚合替代语义聚类（阈值可配），embedding 聚类列为增强；
4. **忠实性边界**：「主题相邻但无答案」问题存在幻觉残留案例（食堂承包商），
   已记录于测试评估报告 §3.2 并规划 groundedness 校验链缓解。

以上偏差均为显式声明的工程取舍，不影响八条验收标准达成。
