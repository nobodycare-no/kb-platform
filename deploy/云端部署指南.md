# kb-platform 云端部署完整流程（腾讯云/阿里云轻量服务器）

> 前提：AutoDL GPU 实例已就绪（三模型已启动）；本地项目可正常运行。
> 目标拓扑：云服务器跑业务平面（8 容器），AutoDL 跑推理平面，公网 HTTPS 可访问。

---

## Step 0 服务器选购与初始化

| 项 | 要求 |
|----|------|
| 规格 | 轻量应用服务器 **4C8G** 起（Milvus 三件套吃内存），磁盘 60GB+ |
| 系统 | Ubuntu 22.04 LTS |
| 防火墙 | 仅放行 **22 / 80 / 443**；3306/6379/19530 一律不放 |

```bash
# SSH 登录后安装 Docker（阿里云镜像源）
curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun
sudo systemctl enable --now docker
docker compose version    # 验证 v2.x+
```

## Step 1 拉取代码

```bash
cd /opt
sudo git clone https://github.com/nobodycare-no/kb-platform.git
sudo chown -R $USER:$USER kb-platform
cd kb-platform
```

## Step 2 上传密钥文件（.env 不在 git 里）

Windows 本机 PowerShell：
```powershell
scp D:\260525\phase9_vibecoding\project\kb-platform\.env 用户@服务器IP:/opt/kb-platform/.env
```
服务器上校验：
```bash
grep -c "=" .env   # 应 ≥ 25 行配置
```

## Step 3 前端构建产物（二选一）

**方案 A 推荐——本机构建后上传**（服务器免装 Node）：
```powershell
# Windows 本机
cd D:\260525\phase9_vibecoding\project\kb-platform\web
npm run build
scp -r dist 用户@服务器IP:/opt/kb-platform/web/
```

**方案 B——服务器装 Node 构建**：
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
cd /opt/kb-platform/web && npm install --registry=https://registry.npmmirror.com && npm run build
```

## Step 4 启动生产栈

```bash
cd /opt/kb-platform/deploy
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build
```

首次会构建 backend / ai-service 镜像并拉取 MySQL/Redis/Milvus 等基础镜像（约 5~15 分钟）。

等待健康检查：
```bash
docker compose ps     # 8 个容器全部 Up(/healthy)
```

## Step 5 初始化数据

```bash
# 种子数据（账号 + 权限矩阵 + 14 篇企业制度语料）
docker compose exec backend python -m app.tools.seed

# AutoDL 开机状态下补建真实向量索引（关机状态可跳过，问答走降级模式）
docker compose exec backend python -m app.tools.reindex
```

## Step 6 验证

```bash
curl -s http://127.0.0.1/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"Abc12345!"}' | head -c 120
# 应返回 {"code":0,...,"access_token":...}
```

浏览器打开 `http://服务器IP` → 登录 admin → AI 对话提问「设备坏了怎么报修？」→
应看到带 [n] 引用的流式回答。

## Step 7 （可选）HTTPS

有域名时：
```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com        # 自动改写 nginx 配置并续期
```
无域名则 IP+80 直接可用（简历演示足够；正式对外建议配域名）。

## 日常运维速查

| 操作 | 命令（均在 deploy/ 下） |
|------|------------------------|
| 更新代码后发布 | `git pull && docker compose build backend ai-service && up -d backend ai-service` |
| 前端更新 | 本机构建 dist → scp 覆盖 → `docker compose restart web` |
| 改模型地址/密钥 | 编辑 `.env` → `up -d --force-recreate backend ai-service` |
| 看日志 | `docker compose logs -f backend` |
| 重建向量索引 | `docker compose exec backend python -m app.tools.reindex` |
| 数据库备份 | `docker compose exec mysql mysqldump -ukb -p$DB_PASSWORD kb_platform > backup.sql` |

## 安全红线回顾

- `.env` 权限 600，永不入 git；
- 防火墙仅 22/80/443，MySQL/Redis/Milvus 全部内网互通；
- JWT_SECRET / INTERNAL_TOKEN / DB_PASSWORD 上线前全部换掉默认值；
- AutoDL 关机省钱——平台降级模式仍可演示检索与管理功能。
